# AI Document Intelligence

An AI-powered document intelligence platform designed primarily for students.

## Overview

AI Document Intelligence allows students to upload academic documents and interact with them using AI.

Instead of simply storing PDFs, the platform understands the content and allows students to:

- Ask questions about their documents
- Get answers with source references
- Generate summaries
- Generate quizzes
- Generate flashcards
- Search across their documents

## Target Users

Primary users:

- University students
- College students
- Researchers and learners
