## 1. Executive Summary

Cognidocs **Document Comparison (Phase 1)** provides an intelligent, semantic comparison engine that allows authenticated users to select any two documents from their library—including standard PDFs, Word documents (DOCX), plain text (TXT), and handwritten notes transcribed via Cognidocs OCR 3.5—and receive:

1. **Grounded AI Comparison Synthesis**: An executive overview generated by local Ollama Llama 3.2, structured into summary prose, key changes, important additions, and analytical implications.
2. **Discrete Classification of Content**:
   - **Similar / Unchanged**: Near-identical or semantically equivalent units ($\text{sim} \ge 0.88$ or normalized text match).
   - **Modified**: Aligned topics where content or terminology was revised ($0.68 \le \text{sim} < 0.88$), presented in a side-by-side comparison with page tags and lexical diff hints.
   - **Added to Document B**: Unmatched sections introduced in the target document.
   - **Removed from Document A**: Unmatched sections present only in the baseline document.
3. **Exact Page & Source Grounding**: Every comparison unit preserves its page citation (`document_a_page`, `document_b_page`).
4. **Sub-60ms Cached Retrieval**: SHA-256 fingerprint hashing of document contents with SQLite persistence (`document_comparisons`), providing an immediate **188.5x speedup** on repeated requests.
5. **Strict Tenant & Safety Boundaries**: Validates user ownership on both documents, rejects cross-tenant comparisons with HTTP 404, and disallows comparing a document with itself (HTTP 400).
6. **Zero Cloud API Calls**: Operates completely on local CPU/GPU using `all-MiniLM-L6-v2` (384-dimensional vectors) and local Ollama.

### 2.1 Paragraph-Aware Chunking & Alignment
Standard document chunks can span arbitrary character lengths. To align discrete claims accurately:
- `split_content_into_comparison_units()` segments text along natural paragraph boundaries (`\n\n`) and sentence clusters.
- Units retain their page number and section category (e.g. `Introduction`, `Networking`, `Security`).
- Pairwise cosine similarities are scored across all chunks $A_i$ and $B_j$. A greedy maximum bipartite matching pairs the most similar units first.
- Lexical diff analysis computes newly introduced words and omitted phrases to provide instant change descriptions.

### 2.2 Handwritten OCR Integration
- Utilizes `get_document_transcription_source()` and `sync_handwritten_chunks_and_embeddings()`.
- Handwritten pages transcribed by TrOCR Small participate with page citations (`Page 1`, `Page 2`, etc.) alongside printed PDFs or DOCX files.
